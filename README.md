# Web Status Checker

A beginner Python project that checks paths from a wordlist and shows their HTTP status codes.

## Features

- Takes a target URL as input
- Reads paths from `wordlist.txt`
- Sends HTTP requests using Python's `requests` library
- Checks HTTP status codes
- Displays successful responses

## Requirements

- Python 3
- `requests`

Install `requests` with:

```bash
pip install requests
```

## Usage

1. Put the paths you want to check in `wordlist.txt`.
2. Run the program:

```bash
python web_status.py
```

3. Enter the target URL when prompted.


## Disclaimer

Only use this tool on websites or systems you own or have explicit permission to test.
